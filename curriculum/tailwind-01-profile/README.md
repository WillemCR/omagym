# Utility profile card

Build a compact profile card using Tailwind utility classes.

## Your brief

- Use Tailwind classes in index.html; styles.css already imports Tailwind. Preserve article.profile and .avatar so measurements can find them.
- Center the card horizontally and vertically inside a main that is at least the viewport height. Card width is 320px, with 24px padding, 16px corner radius and a visible box shadow.
- The avatar is a 64px circle. The h1 uses 24px font size and at least 600 weight. The View projects link is a block, fills the card content width and is at least 44px tall.
- At viewport widths 390px and 1200px the card stays inside the viewport with no horizontal overflow. Choose your own colors.

## Work and check

Start in `index.html`. The starter intentionally leaves the requirements unfinished. Run the browser suite in Omagym after saving; it opens your app in Chromium and checks the rendered DOM and behavior. Tests reset the page for each case. You may reorganize editable files while preserving the public behavior described above. No external services or downloads are needed. Ask the coach for observations and documentation when you get stuck.
