# Native FAQ

Create an interactive FAQ using built-in browser behavior and no JavaScript.

## Your brief

- Create one main with h1 Weekend FAQ and three initially closed details elements.
- Each details element has a summary: What should I bring?, Can I join remotely?, and Is there a deadline? in that order. Answers are Bring a laptop and curiosity., Yes, all exercises run locally., and Finish at your own pace. respectively.
- Pointer and keyboard interaction must open and close each answer using native details/summary behavior. Multiple answers may remain open independently.
- Use no JavaScript; keep answers inside their corresponding details and ensure they are hidden while closed.

## Work and check

Start in `index.html`. The starter intentionally leaves the requirements unfinished. Run the browser suite in Omagym after saving; it opens your app in Chromium and checks the rendered DOM and behavior. Tests reset the page for each case. You may reorganize editable files while preserving the public behavior described above. No external services or downloads are needed. Ask the coach for observations and documentation when you get stuck.
