# Responsive project gallery

Build a responsive card layout that can survive both phone and desktop widths.

## Your brief

- Keep the three .card articles inside .gallery and their titles Parser, Tracker and Journal. Edit styles.css and HTML as needed.
- At a 390px viewport, cards form one full-width column; at 900px and 1200px they form three equal-width columns in one row.
- Use a 24px gap horizontally and vertically. Each card has 24px padding, 12px border radius and a visible non-transparent background.
- The main content is centered, with maximum width 1100px and at least 16px outer space on each side. No horizontal page overflow at 390px or 1200px.

## Work and check

Start in `index.html`. The starter intentionally leaves the requirements unfinished. Run the browser suite in Omagym after saving; it opens your app in Chromium and checks the rendered DOM and behavior. Tests reset the page for each case. You may reorganize editable files while preserving the public behavior described above. No external services or downloads are needed. Ask the coach for observations and documentation when you get stuck.
